# Desi meme sound clips

Drop `.mp3` clips here with these exact names. When a meme sound pack (CID &
Bollywood, Internet memes, or Desi mix — which clip goes in which pack is in
`DESI_LINES` in lib/live/sound.ts) is on, a clip plays if its file is here; otherwise the phone says the
line in Hindi (clips marked *clip only* stay silent and another line is said).

Use only clips you have the right to use — the app is public.
